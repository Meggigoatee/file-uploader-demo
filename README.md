# File Uploader Demo

확장자 차단 정책을 DB에 저장하고, 서버가 해당 정책으로 실제 파일 업로드를 허용하거나 거절하는 과제 프로젝트입니다. 약 6시간의 개발 범위에서 필수 기능과 합의한 핵심 UX를 완성하는 것을 목표로 합니다.

수정된 계획을 승인받아 **S0~S6 구현·회귀와 S8 배포·원격 검증을 완료**했습니다. [공개 데모](https://file-uploader-demo.meggigoatee.workers.dev)에서 정책 DB/API, 비공개 파일 저장, 다중 업로드 화면을 사용할 수 있습니다. 기존 의존성과 PC 전역 pnpm 스토어를 유지했습니다. 실행 방법은 [개발 문서](.docs/README.md#로컬-실행), 실패 원인·리팩토링·회귀 결과는 [TDD 기록](.docs/TDD_LOG.md)에 있습니다.

2026-10-23 **익명 세션별 정책과 카테고리 관리를 공개 배포하고 운영 검증까지 완료**했습니다. 새 세션은 고정7개 체크 해제·커스텀0개이며, 같은 세션 새로고침은 유지됩니다. 같은 브라우저의 탭은 세션을 공유하며 앱 전체 저장 예산도 유지합니다. 배포 환경 통과 후 두 세션과28바이트 파일2개로 검증했고, 원격 R2 바이트/해시를 확인한 테스트 데이터만 정리했습니다. [배포·운영 기록](.docs/RELEASE_20261023.md)을 확인할 수 있습니다.

## 구현 목표

최신 카테고리 UI는 **단일 전체 차단/허용 버튼·고정과 같은 개별 체크박스·공통 팝업**으로 통일했습니다. 기본 카테고리도 +/×로 확장자를 추가·제외하고, 사용자 이름/생성/삭제는 입력·확인 팝업을 사용합니다. 최종 로컬 검증에서 누락된 경계48개를 보강해 **단위65/Worker57/E2E29=151개와 타입/빌드**가 통과했습니다. [구현·테스트 대응표](.docs/FINAL_LOCAL_REVIEW.md)와 [실제 실행 결과](.docs/VALIDATION.md)를 확인할 수 있습니다. 카테고리 삭제 시 소속 확장자 차단도 해제됩니다. 공개 데모에도 반영했습니다.

| 구분 | 범위 |
| --- | --- |
| 필수 | 고정 확장자 7종의 즉시 저장·유지, 커스텀 확장자 최대 20자·200개·중복 방지·삭제, 서버의 정책 검사와 실제 파일 저장 |
| 핵심 추가 | 다중 선택·드롭, 전송 대기 목록·사전 검사·제외, 파일별 진행률·결과, 실패 파일 수동 재시도, 대표 확장자 안내와 등록 여부 확인 |
| 후속 카테고리 | 카테고리 조회 필터·일괄 차단/허용, 새 세션 기본 분류별5개, 기본/사용자 소속 편집과 사용자 카테고리 생성·이름 변경·삭제. 삭제하면 현재 소속 확장자 차단도 해제합니다. 공개 배포·운영 검증을 완료했습니다. |

기술 구성은 **Vue 3 Composition API + TypeScript + Vite / Cloudflare Workers + D1 + 비공개 R2**입니다. Node.js/pnpm은 개발 도구, Vitest·Playwright는 검증에 사용합니다. 설치 버전은 [개발 환경](.docs/DEVELOPMENT.md), 선정한 스킬·출처·CLI 하네스는 [스킬과 하네스](.docs/HARNESS.md)에 있습니다. 실제 원격 결과는 [검증 원장](.docs/VALIDATION.md)에서 로컬 결과와 구분합니다.

## 작업 원칙

- 기능 개발·검증은 [로컬 데브 환경](.docs/README.md#로컬-실행)을 우선 사용하며, Cloudflare 배포는 이후 사용자의 명시적 요청이 있을 때만 수행합니다.
- 승인된 단계별 TDD 계획에 따라 테스트·구현·회귀를 수행하고 실제 실패와 결과를 기록합니다.
- 필수 목표, 합의한 핵심 추가 기능, 시간 여유 옵션을 구분하고 불필요한 추상화·기능 확장을 줄입니다.
- 상세 계획·설계·검증·AI 활용·대화 기록은 `.docs`에 둡니다. 루트의 이 파일과 [AGENTS.md](AGENTS.md)는 프로젝트 진입점과 작업 지침입니다.
- 변경 시 관련 문서를 함께 갱신하고, 검증 계획과 실제 실행 결과를 구분합니다. 실행 방법은 구현하고 확인한 명령만 추가합니다.

자동화 에이전트는 작업 전에 [AGENTS.md](AGENTS.md)를 읽습니다. Cloudflare 실제 장애·계정 한도 응답의 모방 검사는 제외했습니다.
