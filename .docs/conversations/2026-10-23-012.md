# 검증 변경 커밋·푸시·배포와 제한된 운영 검증

- 2026-10-23 21:48:03 KST 최초 도구 확인 시각. 사용자 전송 시각은 알 수 없다.

## 사용자 원문

이제 검증된 변경 사항을 커밋하고 origin에 푸시한 뒤 Cloudflare에 배포한다. 배포가 완료되면 운영 테스트를 수행한다.
배포 환경에서도 세션 분리, 카테고리·정책 관리, 실제 업로드 저장을 최종 검증하고 결과를 기록한다.
환경 검증에 실패하면 분석, 해결될 때 까지 운영 테스트는 수행하지 않는다.
운영 테스트에서는 부하 테스트, 대량 파일 업로드 테스트를 금지한다.

## AI 중간 응답

- 검증된 변경 범위와 Git 상태를 확인한 뒤 커밋·origin 푸시·Cloudflare 배포를 진행하겠습니다. 배포 환경 점검이 통과한 후에만 작은 테스트 파일로 세션 분리, 카테고리·정책 관리, 실제 저장을 확인하고 결과를 기록하겠습니다.
