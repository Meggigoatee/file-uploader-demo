## 동작과 작은 설계

- 기본 사진/영상/음성/문서 소속의 새 세션 초기값은 각5개다. CATEGORY-03부터 소속 추가/제거를 허용하며 개별 체크박스가 차단/허용을 즉시 저장한다. 과거 안내 클릭-입력 채움은 최신 사용자 지시로 대체했다.
- 필터는 커스텀 차단 목록만 좁히며 고정 7개는 유지한다. 필터 표시 수와 전체 200개 한도를 구분한다. 전체/기타/기본·사용자 카테고리를 선택할 수 있다.
- 기본/사용자 카테고리 차단은 소속 확장자 전체에 적용한다. 고정은 체크값 변경, 나머지는 커스텀 차단 목록에 추가한다. 허용은 고정 체크 해제·소속 커스텀 삭제다. 수동 등록값과 다른 카테고리에도 속한 확장자도 같은 현재 정책을 공유한다. 카테고리별 별도 우선순위/boolean은 만들지 않는다.
- 사용자 카테고리의 이름과 확장자 목록을 생성/수정/삭제한다. 빈 목록으로 생성할 수 있다. 이름 1~30자·확장자 최대50개는 작은 데모를 위한 AI 설계값이며 사용자 원문 요구값이 아니다. 확장자는 기존 정규화 규칙으로 검증·중복 제거한다.
- 카테고리와 구성원은 D1에 세션별 저장한다. 작업 폴더에서 진행 중인 익명 세션 분리 구현을 보존하고 `session_extension_policies`와 연결한다. 전역 공유 정책으로 되돌리지 않는다.
- 일괄 차단은 현재 개수+새 확장자 수가 200 이하일 때만 한 INSERT/UPSERT로 처리한다. 같은 DB의 동시 요청에도 상한을 넘지 않는다. 허용/카테고리 삭제/구성원 편집은 D1 batch로 전부 성공 또는 rollback한다.
- 저장 중 정책/업로드 조작 잠금, 응답 유실 시 불확실 표시·재조회 전 잠금, 업로드 판정 T·완료 결과 보존을 유지한다.

## 테스트 선행·루프

한 기능 묶음으로 Worker와 UI 테스트를 먼저 작성해 실제 Red를 기록한다. 이어 최소 구현→작은 함수/컴포넌트 정리→단위/실제 D1·R2 통합/전체 핵심 E2E·타입/빌드를 누적 회귀한다. 사용자 구현 지시가 현재 범위의 승인이다. 별도 재승인 대기로 중단하지 않는다.

1. Worker: 기본 사전 각5개·조회 무변경, 카테고리 CRUD/정규화/세션 격리, 고정+커스텀 일괄 차단/허용, 200개 경계/동시성/전체 취소, 삭제의 차단 해제, 실제 DB batch 실패 rollback, 실제 R2 업로드 적용.
2. UI: 필터 조회 쓰기 없음·표시수/전체수, 기본 각5개 안내·일괄 버튼, 사용자 카테고리 생성/편집/새로고침 유지/삭제, 사전 검사와 실제 업로드 연동, 처리 잠금/응답 유실 복구, 모바일 렌더.
3. 기존 회귀: T·예산·정책 CRUD·응답 손실/60초 timeout·재시도·새 세션 격리를 포함한 현재 테스트 전체. 실제 Cloudflare 장애 모방·원격 검증은 수행하지 않는다.

실제 명령·실패 원인·리팩토링·결과는 [TDD_LOG](./TDD_LOG.md), [VALIDATION](./VALIDATION.md)에 기록한다. [Worker 스킬](../.agents/skills/uploader-worker-checks/SKILL.md)과 [UI 스킬](../.agents/skills/uploader-ui-checks/SKILL.md)을 사용한다.
