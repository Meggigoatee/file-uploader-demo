- `web.run`: Cloudflare Vue/Vitest 연동, Vue TypeScript, pnpm 설정·빌드 허용, Playwright 브라우저 공식 문서를 확인. Node fetch로 npm 공식 레지스트리의 실제 버전·engines·peerDependencies·dependencies를 조회해 호환성을 확인.
- 기존 캐시의 Vue 3.5.41(3.5.35도 존재), TypeScript 5.6.3, Vite 6.4.3, Vue 플러그인 5.2.4, vue-tsc 2.2.12, Node 타입 22.20.1(25.9.1도 존재), Wrangler 4.127.1, Vitest/runner/snapshot 4.1.10을 선택. 프로젝트의 기존 의존성을 업데이트한 것은 아니며 신규 등록 시 캐시 버전을 재사용한다.
- 최신 Cloudflare Vite 플러그인 1.64.0은 Wrangler ^4.151.0이 필요해 미선택. Vite 플러그인 1.54.2와 Vitest 플러그인 1.1.2는 모두 기존 Wrangler 4.127.1/workerd/Miniflare와 맞으므로 선택. 공식 명칭인 `@cloudflare/vitest-plugin`을 사용하고 폐기 예정인 옛 pool 패키지는 추가하지 않는다.
- `@vitest/runner`와 `@vitest/snapshot`은 선택한 Cloudflare 테스트 플러그인의 필수 peer이므로 Vitest와 같은 4.1.10을 직접 고정한다. Workers 타입은 향후 `wrangler types`로 생성하므로 별도 workers-types 패키지는 추가하지 않는다.
- Playwright 패키지/브라우저 캐시는 없어 `@playwright/test` 1.64.1을 신규 선택. 기본 E2E 준비용 Chromium/Headless Shell과 필요한 FFmpeg/Winldd를 PC 공용 브라우저 캐시에 설치하고 기동 확인했다.
- `apply_patch`: 최소 package.json, pnpm 설정용 pnpm-workspace.yaml, 캐시·비밀값·로컬 상태를 제외하는 .gitignore와 이 기록 생성. pnpm 설정 파일은 루트 패키지 하나만 다루며 모노레포를 만들지 않는다. storeDir를 저장소에 고정하지 않고 PC 기본 공유 스토어를 따른다.
- 런타임 의존성은 Vue, 나머지는 개발 의존성으로 구분. Express/ORM/DB 드라이버/R2 SDK/라우터/상태관리/UI 프레임워크는 현재 설계에 필요하지 않다. 업로드·드롭·진행률은 브라우저 표준 API로 구현할 계획이다.
- 별도 스킬·플러그인·서브에이전트 미사용. 기존 도구 발견 목록을 조회했으나 외부 앱 도구는 호출하지 않았다. 사용자에게 재질문하지 않았고 세부 선택을 사용자 원문 승인으로 기록하지 않는다.
