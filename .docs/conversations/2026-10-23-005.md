# 카테고리 삭제의 차단 해제 동작 선택

- 기록: 2026-10-23, 카테고리 구현 중 수신. 사용자 전송 시각 미제공.
- 질문: “사용자 카테고리를 삭제할 때, 소속 확장자의 차단 정책은 어떻게 처리할까요?”
- 사용자 원문 답변: “소속 확장자의 차단도 함께 해제”
- 반영: 카테고리 삭제와 고정 체크 해제/소속 커스텀 차단 삭제를 같은 D1 batch로 처리한다. 공유 확장자도 현재 차단 정책이 해제되며 이 의미를 UI에 안내한다. 원격 저장 파일 삭제나 예산 환급을 뜻하지 않는다.
- AI: “카테고리 삭제 시 소속 확장자의 차단도 함께 해제하도록 반영하겠습니다.” 후 원래 구현 작업을 계속했다. 상세 진행·검증·최종 응답은 [원래 구현 대화](./2026-10-23-004.md)에 이어 기록한다.
